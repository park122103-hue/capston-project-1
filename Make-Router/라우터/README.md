
## Files  
|File|Description|
|---|-----|
|main.cpp|메인함수. 테스트할 양자 회로와 물리 노드 간선이 하드코딩 되어있다. 이니셜 매핑으로 객체의 매핑 배열을 완성 시킨 뒤 라우팅을 한다. 아직 로직이 미완성인 상태이므로(심지어 control qubit과 target qubit 구분도 안되어 있음) 가져다 쓴다면 제게 먼저 코딩 의도를 물어봐주기를 바랍니다.|
|QCompiler.h|컴파일에 관한 각종 함수들과, 매핑, 라우팅 전반에 대한 클래스를 정의한 헤더. 크게 전처리를 위한 set 계열 함수, 매핑을 위한 mapping 계열 함수, 그리고 라우팅을 위한 routing 계열 함수로 나눌 수 있다.|
|data_preprocessing.cpp|클래스의 생성자와 set 계열 함수들을 구현한 코드. 물리 노드 간선 리스트를 받아 인접 노드 리스트(adj)와 거리 행렬(dist)로 바꾸는 함수, 그리고 양자 게이트 리스트를 받아 Glist와 grid(버블그리드)로 바꾸는 함수가 구현되어 있다. 또한 약간의 시간 복잡도 이득을 위하여 중심도(Centrality)와 중요도(Importance)를 선계산하여 배열에 저장해두는 로직도 구현되어 있다.|
|initial_mapping.cpp|이니셜 매핑을 구현한 코드.|
|routing.cpp|라우팅을 구현한 코드. 비용을 줄이는 방향으로 스왑을 하게 되는데, 이는 사실 상호작용 하고자 하는 두 큐비트간의 거리를 줄이는 방향이라는 보장이 없다(지금 당장 처리할 큐비트는 비용이 높게 책정되므로 확률은 좀 높겠지만). 따라서 무한히 핑퐁할 수도 있다. 그러한 문제가 있는 코드이다. 절대 가져다 쓰지 말 것!|
